# **App Name**: FaceAttend

## Core Features:

- Face Recognition: Facial recognition for attendance taking. The system will use a tool to verify if the detected face is present in the student database, and mark attendance accordingly.
- User Roles & Access: Separate dashboards for students and faculty. Students can view their attendance records. Faculty can view and manage attendance records for all students.
- Data Storage: Secure storage of student data including facial biometric data in a database (i.e. Firestore).
- Authentication: Login and signup page for new users

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for a professional and trustworthy feel.
- Secondary color: Light gray (#EEEEEE) for backgrounds and content separation.
- Accent: Teal (#009688) for interactive elements and highlights.
- Clean and well-spaced layout for easy navigation and readability.
- Use clear and recognizable icons for attendance status (present, absent, late).
- Subtle animations for feedback on attendance actions (e.g., a checkmark animation when attendance is successfully marked).

## Original User Request:
Make an atttendance management app using facial recognition which saves user data in database and have separate access to faculty and students and faculty can access to any student database
